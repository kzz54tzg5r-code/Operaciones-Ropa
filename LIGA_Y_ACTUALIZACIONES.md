# Liga y actualizaciones

Cuando Operaciones Ropa se publique en internet, se mantiene la misma liga.

Ejemplo:
https://operaciones-ropa.onrender.com

Cada vez que actualicemos diseño, reportes, cálculos o módulos:
- se despliega la nueva versión sobre el mismo servicio;
- la URL permanece igual;
- el usuario sólo recarga la página;
- si el navegador conserva una versión anterior, se usa Ctrl+F5.

La liga sólo cambia si se crea deliberadamente otro servicio o dominio.

La URL local de V9 es:
http://127.0.0.1:8020

Esa URL local sólo funciona en la PC donde corre el sistema.
